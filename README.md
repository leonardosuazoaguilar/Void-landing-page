# VØID Flag Football - Landing Page

## Descripción del proyecto

Este proyecto es una landing page moderna, responsiva y de alto rendimiento diseñada exclusivamente para la identidad, comunidad y patrocinadores del equipo **VØID Flag Football**. Su funcionalidad principal es presentar al equipo de manera profesional, exhibir sus valores, dar visibilidad a sus patrocinadores oficiales y servir como canal de captura de prospectos. El sitio utiliza una estética "dark mode" minimalista y agresiva estructurada para garantizar una navegación impecable y una experiencia visual de alto impacto.

## Tecnologías y técnicas utilizadas

- **HTML5 semántico:** Estructuración limpia y accesible utilizando etiquetas nativas para mejorar el SEO y la legibilidad del código.
- **CSS3 Avanzado (Variables nativas):** Implementación de una arquitectura modular basada en propiedades personalizadas (`:root`) para gestionar de forma centralizada la paleta de colores, tipografías personalizadas (Lovelo/Inter) y espaciados, facilitando futuros cambios de branding.
- **Flexbox y CSS Grid:** Combinación de layouts modernos; Flexbox para la alineación y distribución del menú de navegación, botones y componentes lineales, y CSS Grid para la cuadrícula responsiva y asimétrica de las tarjetas de valores, testimonios y patrocinadores.
- **Diseño Responsivo (Media Queries):** Adaptación fluida de la interfaz planteada desde una estrategia mobile-first hacia pantallas de escritorio, asegurando que ningún elemento desborde su contenedor.
- **Efectos y Posicionamiento Avanzado:** Uso de `position: sticky` combinado con `backdrop-filter` para crear una cabecera flotante con efecto de vidrio esmerilado, junto con capas de `position: absolute` y gradientes radiales complejos para generar efectos dinámicos de iluminación ambiental en el fondo.
- **Optimización y Accesibilidad:** Cero dependencias de frameworks externos para garantizar una carga ultra rápida y el uso de media queries avanzadas (`prefers-reduced-motion`) para respetar las preferencias de rendimiento y accesibilidad del usuario.
